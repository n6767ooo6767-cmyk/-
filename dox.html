📄 Как создать и использовать planet.bat

Эта инструкция объясняет, как создать обычный Windows BAT-файл, загрузить его в GitHub и скачать его через HTML-страницу.

1. Что такое .bat

Файл с расширением .bat — это текстовый файл Windows, содержащий команды командной строки. Он выполняется только после явного запуска пользователем в Windows.

2. Как создать planet.bat

  1. Открой Windows и запусти «Блокнот».
  2. Напиши нужные команды в текстовом файле.
  3. Выбери Файл → Сохранить как.
  4. В поле имени укажи planet.bat.
  5. В поле типа выбери Все файлы.
  6. Сохрани файл.
Важно: не сохраняй его как planet.bat.txt. Если расширения файлов скрыты, Windows может показать неочевидное имя.

3. Проверка файла

Перед публикацией проверь, что файл действительно называется planet.bat. Открой его через Блокнот и убедись, что внутри находятся именно те команды, которые ты собирался использовать.

4. Загрузка в GitHub

  1. Открой свой репозиторий.
  2. Нажми Add file → Upload files.
  3. Перетащи planet.bat на страницу.
  4. Убедись, что файл находится в корне репозитория, если HTML использует путь /main/planet.bat.
  5. Нажми Commit changes.

5. Где должен находиться файл

-/
├── planet.bat
├── dox.html
└── ...

Если planet.bat находится в другой папке, путь в HTML-кнопке Download нужно изменить.

6. Как скачать файл

Для твоего репозитория HTML может использовать raw-ссылку:

https://github.com/n6767ooo6767-cmyk/-/raw/refs/heads/main/planet.bat

Кнопка Download только передаёт браузеру запрос на скачивание. Сам HTML не запускает BAT-файл.

7. Как запустить файл в Windows

После скачивания открой папку загрузок и найди planet.bat. Перед запуском убедись, что ты доверяешь его содержимому. Двойной щелчок по BAT-файлу запускает записанные в нём команды Windows.

Безопасность: не запускай неизвестные BAT-файлы. BAT-файлы могут выполнять команды с правами текущего пользователя, поэтому сначала всегда проверяй их содержимое.

8. Если Copy не работает

Современные браузеры могут ограничивать доступ к буферу обмена. Кроме того, чтение файла с другого источника может быть ограничено политиками безопасности браузера. Поэтому на странице предусмотрена запасная кнопка OR DOWNLOAD.

9. Рекомендуемая структура страницы

<button>Copy</button>

OR

<a href=".../planet.bat" download>
    Download planet.bat
</a>

10. Если появляется ошибка 404

Проверь три вещи:

  • файл называется точно planet.bat;
  • файл находится в правильной ветке, например main;
  • путь в URL соответствует расположению файла.

11. Итог

Создай planet.bat → проверь его содержимое → загрузите его в GitHub → проверь путь → используй HTML-кнопку Copy или Download.
